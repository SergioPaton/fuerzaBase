## 1. Idioma de Comunicación
- Todo el razonamiento, las explicaciones, los comentarios en el código y las respuestas proporcionadas por el asistente deben ser estrictamente en **español**.
## 2. Resumen Post-Modificación
- **Obligatorio:** Inmediatamente después de realizar cualquier cambio, modificación o creación de archivos, debes proporcionar un resumen conciso y claro en español detallando exactamente qué cambios has realizado y por qué.
## 3. Arquitectura y Estructura
- **Backend (FastAPI):** Seguir arquitectura limpia separando rutas (routers), modelos de base de datos (SQLAlchemy), esquemas de validación (Pydantic) y servicios de lógica de negocio.
- **Frontend (React):** Componentes limpios, modulares y con diseño responsivo mobile-first utilizando Tailwind CSS.

## 4. Calidad de Código y Tipado
- Utilizar tipado estricto tanto en Python como en la interfaz para prevenir errores.
- Incluir un manejo de errores robusto con códigos de estado HTTP correctos en el backend.
## 5. Control de Versiones
- Los commits automáticos deben seguir el estándar de Conventional Commits (ej. `feat:`, `fix:`, `refactor:`, `chore:`).
